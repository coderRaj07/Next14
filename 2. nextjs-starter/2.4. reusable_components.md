### **Card Component (Reusable)**

This component takes data as props and renders the card dynamically.

```jsx
// Card.js
import React from "react";

const Card = ({ title, description, value, icon, bgColor }) => {
  return (
    <div
      className={`flex items-center justify-between p-6 rounded-lg shadow-md ${bgColor}`}
    >
      <div>
        <h3 className="text-lg font-semibold text-white">{title}</h3>
        <p className="text-3xl font-bold text-white mt-2">{value}</p>
        <p className="text-sm text-white opacity-75 mt-1">{description}</p>
      </div>
      <div className="text-white text-4xl">{icon}</div>
    </div>
  );
};

export default Card;
```

---

### **Parent Component Rendering Cards Dynamically**

The parent component imports and uses the `Card` component. The data is passed as props dynamically.

```jsx
// Dashboard.js
import React from "react";
import Card from "./Card";
import { FaUsers, FaDollarSign, FaClipboardList, FaChartLine } from "react-icons/fa";

const Dashboard = () => {
  // Dynamic Data for Cards
  const cardData = [
    {
      id: 1,
      title: "Total Users",
      description: "Registered Users",
      value: "1,245",
      icon: <FaUsers />,
      bgColor: "bg-blue-500",
    },
    {
      id: 2,
      title: "Revenue",
      description: "Total Revenue Generated",
      value: "$32,500",
      icon: <FaDollarSign />,
      bgColor: "bg-green-500",
    },
    {
      id: 3,
      title: "Tasks",
      description: "Pending Tasks",
      value: "86",
      icon: <FaClipboardList />,
      bgColor: "bg-yellow-500",
    },
    {
      id: 4,
      title: "Growth",
      description: "Monthly Growth",
      value: "+15%",
      icon: <FaChartLine />,
      bgColor: "bg-purple-500",
    },
  ];

  return (
    <div className="min-h-screen bg-gray-100 p-6">
      <h1 className="text-2xl font-bold mb-6">Admin Dashboard</h1>
      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-6">
        {cardData.map((card) => (
          <Card
            key={card.id}
            title={card.title}
            description={card.description}
            value={card.value}
            icon={card.icon}
            bgColor={card.bgColor}
          />
        ))}
      </div>
    </div>
  );
};

export default Dashboard;
```

---

### **Explanation**:

1. **`Card` Component**:
   - Receives `title`, `description`, `value`, `icon`, and `bgColor` as props.
   - Uses Tailwind CSS for styling.
   - Renders content dynamically based on the passed props.

2. **Dynamic Data in `Dashboard`**:
   - `cardData` is an array of objects containing the necessary information for each card.
   - Icons are imported from `react-icons` and passed as JSX.

3. **Grid Layout**:
   - `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-6` ensures the cards are responsive:
     - 1 column for small screens.
     - 2 columns for medium screens.
     - 4 columns for large screens.

4. **Icons**:
   - Used `react-icons` for adding icons dynamically (`FaUsers`, `FaDollarSign`, etc.).

---

### **How It Looks**:
- Each card dynamically displays its:
  - **Title**
  - **Value**
  - **Description**
  - **Icon**
- Cards have different background colors (`bg-blue-500`, `bg-green-500`, etc.) to visually distinguish them.

3. Import and render the `Dashboard` component in your `App.js` file.
