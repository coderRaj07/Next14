### Combining Grid and Flexbox

Often, **Grid** is used for layout and **Flexbox** is used within grid items for fine-grained alignment. Check the following example.

#### Example Code:

```html
<div class="grid grid-cols-3 gap-4 h-screen">
  <!-- First Grid Item -->
  <div class="bg-blue-200 flex items-center justify-center">
    <p class="text-lg font-semibold">Item 1</p>
  </div>

  <!-- Second Grid Item -->
  <div class="bg-green-200 flex items-start justify-end p-4">
    <p class="text-lg font-semibold">Item 2</p>
  </div>

  <!-- Third Grid Item -->
  <div class="bg-yellow-200 flex flex-col items-center justify-between p-4">
    <p class="text-lg font-semibold">Item 3</p>
    <button class="bg-blue-500 text-white px-4 py-2 rounded">Click Me</button>
  </div>
</div>
```

#### How It Works:
1. **Grid** (`grid`, `grid-cols-3`) is used to create a 3-column layout.
2. **Gap** (`gap-4`) adds spacing between the grid items.
3. Each grid item uses **Flexbox** (`flex`) for alignment:
   - `items-center` and `justify-center` align content centrally.
   - `items-start` and `justify-end` control vertical and horizontal alignment.
   - `flex-col` and `justify-between` manage column direction and spacing.
4. Tailwind's utility classes make combining Grid and Flexbox seamless and clean.

### **1. `h-screen`**
- **Definition**: Sets the height of an element to **100% of the viewport height**.
- **Usage**: 
  - Useful for creating full-height layouts like a sidebar, hero section, or landing page.
  
- **CSS Equivalent**:
  ```css
  height: 100vh;
  ```

- **Example**:
  ```html
  <div class="h-screen bg-blue-500">
    This div takes up the entire height of the viewport.
  </div>
  ```

---

### **2. `min-h-screen`**
- **Definition**: Sets the **minimum height** of an element to **100% of the viewport height**.
- **Usage**: 
  - Ensures that the element is at least as tall as the viewport but can grow taller if the content exceeds the viewport height.
  - Often used for pages with scrollable content or layouts where content can extend beyond the viewport.

- **CSS Equivalent**:
  ```css
  min-height: 100vh;
  ```

- **Example**:
  ```html
  <div class="min-h-screen bg-green-500">
    This div will always be at least the height of the viewport but will grow taller if there’s more content.
  </div>
  ```

---

### **3. `flex-1`**
- **Definition**: Tells an element to **grow and take up the remaining available space** in a flex container.
- **Usage**: 
  - Typically used in layouts with `flex` to allow an element to dynamically adjust its size relative to sibling elements.
  - Ensures the element fills the remaining space after other elements take their defined sizes.

- **CSS Equivalent**:
  ```css
  flex: 1 1 0%;
  ```

- **Example**:
  ```html
  <div class="flex h-screen">
    <!-- Sidebar with fixed width -->
    <div class="w-1/4 bg-red-500">Sidebar</div>
    <!-- Main Content taking remaining space -->
    <div class="flex-1 bg-blue-500">Main Content</div>
  </div>
  ```

  In this example:
  - The sidebar has a fixed width of 25%.
  - The main content (`flex-1`) dynamically takes up the remaining space.

---

### **When to Use Them?**

| **Utility**      | **When to Use**                                                                                                                                 |
|-------------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| **`h-screen`**   | When you want an element to **completely fill the viewport's height**, such as for full-page sections or hero banners.                          |
| **`min-h-screen`** | When the content may exceed the viewport height, but you still want the minimum height to match the viewport (e.g., layouts with scrollable content). |
| **`flex-1`**     | When you want an element in a **flex container** to grow and take up the remaining space (e.g., responsive main content next to a sidebar).      |
